# E2E テストシナリオ

## CLI 動作確認

| # | 手順 | 確認観点 | 期待値 |
|---|------|---------|--------|
| 1 | `zip2addr 1000001` | 正常な郵便番号で検索 | 東京都千代田区千代田の JSON が出力される |
| 2 | `zip2addr 100-0001` | ハイフン付き入力 | 同上（ハイフンが正規化される） |
| 3 | `zip2addr １００－０００１` | 全角入力 | 同上（全角が半角に正規化される） |
| 4 | `zip2addr 0000000` | 存在しない郵便番号 | `null` が出力され、終了コード 1 |
| 5 | `zip2addr` | 引数なし | エラーメッセージが表示される |
| 6 | `zip2addr --version` | バージョン表示 | 現在のバージョンが表示される |
| 7 | `zip2addr 1000001 --debug` | デバッグログ | 検索ログが標準エラーに出力される |
| 8 | `zip2addr 6180000` | 複数候補がある郵便番号 | リスト形式で複数の住所が出力される |

## Python API 動作確認

| # | 手順 | 確認観点 | 期待値 |
|---|------|---------|--------|
| 1 | `lookup('1000001')` | 基本検索 | `Zip2Addr` のリストが返る |
| 2 | `lookup('100-0001')` | ハイフン付き | 同上 |
| 3 | `lookup('')` | 空文字 | 空リストが返る |
| 4 | `lookup('0000000')` | 存在しない番号 | 空リストが返る |
| 5 | `results[0].to_dict()` | 辞書変換 | 全フィールドを含む辞書が返る |
