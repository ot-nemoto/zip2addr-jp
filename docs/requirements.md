# 要件定義

## 機能要件

### 郵便番号検索

- 郵便番号を入力し、該当する住所情報をすべて返す
- 対応する入力形式:
  - ハイフン付き: `100-0001`
  - ハイフンなし: `1000001`
  - 全角数字: `１００－０００１`
- 同一郵便番号に複数の住所が存在する場合、すべての候補を返す
- 該当なしの場合は空リストを返す

### CLI

- `zip2addr <郵便番号>` で住所を JSON 形式で標準出力に出力する
- 単一結果はオブジェクト、複数結果はリストとして出力する
- `--version` でバージョン表示
- `--debug` でデバッグログ出力

### データ管理

- 日本郵便の `utf_ken_all.csv` から SQLite データベースを生成する
- データベースはパッケージに同梱する（`src/zip2addr/zip2addr.db`）
- 月次で日本郵便のデータ更新を自動チェックする

## 非機能要件

- **依存関係**: 外部パッケージへの依存なし（Python 標準ライブラリのみ）
- **対応 Python**: 3.9 以上
- **パフォーマンス**: SQLite インデックスによる高速な検索
- **データ鮮度**: 月次の自動チェックにより最新データを維持
