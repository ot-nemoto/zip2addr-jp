# プロダクト概要

## 目的

日本の郵便番号から住所を高速に検索する Python ライブラリを提供する。日本郵便の公開データを SQLite データベースとしてパッケージに同梱し、外部依存なしでインストール後すぐに利用できるようにする。

## 対象ユーザー

- 日本の住所データを扱う Python アプリケーション開発者
- 郵便番号から住所を逆引きする機能を組み込みたいサービス開発者
- コマンドラインで郵便番号を素早く調べたいユーザー

## 成功指標

- インストール後、追加設定なしで郵便番号検索が利用可能であること
- 日本郵便の公開データと同期した最新のデータを提供し続けること
- Python API・CLI の両方で利用可能であること
